# Blackwire

Игра про хакера: свой виртуальный компьютер с терминалом, файлами, пользователями, процессами,
почтой и браузером; сеть из корпораций, банков, больниц, центров безопасности и домашних ПК со своими подсетями;
скриптовый язык **Adder** (по духу Python) для своих программ. Легенда — `docs/STORY.md`.

Главная особенность: **каждое приложение игры — отдельное настоящее окно Windows** (своя кнопка на панели задач,
сворачивание, разворачивание, перенос на любой монитор, раскладка «стеной экранов»), а мир один — в процессе игры.
Вид — как в фильме «Рыба-меч»: тёмная глубина, циан, стекло, проволочные фигуры, потоки шестнадцатеричных цифр.

Стек: Rust + Tauri 2, интерфейс — чистый HTML/CSS/JS без Node и библиотек. Один exe.

## Устройство

| Папка | Что |
|-------|-----|
| `lang/` | крейт `blackwire-lang` — язык Adder: лексер, разбор, исполнитель, встроенные функции (`lang/README.md`) |
| `core/` | крейт `blackwire-core` — ядро: файловая система, пользователи, процессы, сеть и организации, оболочка, мир и сохранение (`core/README.md`) |
| `app/` | крейт `blackwire` — оболочка Tauri: окна, мониторы, команды моста, потоки скриптов, часы мира |
| `app/ui/` | интерфейс: один `index.html` на все окна, темы, рабочий стол, приложения (`app/ui/README.md`) |
| `docs/` | `ADDER.md` — описание языка (вшивается в exe, показывается в справке); `CORE-CONTRACT.md`, `UI-CONTRACT.md` — договорённости между частями; `STORY.md` — легенда |
| `tools/` | `shot.ps1` — снимок монитора для проверки окон |

Что уже есть (первый этап): вход и новая личность; рабочий стол-подложка (всегда позади, на любом мониторе) с полосой
состояния, доком и уведомлениями; окна: терминал (своя оболочка `bwsh`, ~80 команд, конвейеры, ssh по цепочке, scan/ping с
задержками), редактор с подсветкой Adder и проверкой ошибок, файлы, браузер игровой сети, почта, монитор, карта сети, настройки
(12 тем, эффекты, мониторы, раскладка окон), справка; язык Adder с модулями sys/fs/net/shell; мир из 109 машин и 21 организации
(провайдер, корпорации, банки, больницы, SOC, киберполиция, университет, хостинг, правительство, СМИ, магазин, домашние ПК,
приманка, скрытая сеть hello-world) с подсетями, службами, пользователями, файлами, журналами и почтой; письмо-приглашение и
страница `gate.hw/invite/<код>` с первым испытанием.

### Оболочка Tauri (`app/src`)

- `main.rs` — сборка приложения, список команд, окно входа при старте.
- `state.rs` — `AppState`: игра под мьютексом, список окон, работающие скрипты, путь сохранения (`%APPDATA%\top.blackwire.game\save.json`).
- `windows.rs` — окна приложений без системной рамки (`open_app`), подложка рабочего стола во весь монитор и всегда позади
  (`open_desktop`, `desktop_on`), список мониторов (`monitors`), раскладка окон сеткой/колонками/рядами/каскадом (`arrange_windows`),
  `focus_window`, `close_window`, `list_windows`, событие `windows_changed`.
- `cmd_game.rs` — `boot`, `new_game`, `load_game`, `save_game`, `login`, `start_desktop`, `quit`, `settings_get/set` (событие `theme_changed`).
- `cmd_shell.rs` — сеансы терминала (`shell_open/close/exec/complete/prompt/history`), действия ядра для окон (`UiAction`), запуск скриптов
  (`script_run`, `script_input`, `script_kill`), проверка `adder --check`.
- `cmd_fs.rs` — файлы для окон (`fs_*`, событие `fs_changed`), `lang_check`, `lang_doc`, `shell_doc`.
- `cmd_sys.rs` — `sys_status`, `sys_kill`, `net_map`, `web_get`, почта (`mail_*`).
- `scripts.rs` — поток на скрипт; `Host` для языка: печать → событие `script_out`, ввод → `script_input_wanted`, игровые функции →
  `blackwire_core::script_host::call`, остановка по `kill`/Ctrl+C.
- `ticker.rs` — раз в секунду `world_tick`, новые письма (`mail_new`), автосохранение раз в минуту.
- `checks.rs` — проверочный запуск без экрана входа (см. «Проверка»).

Команды, которые создают окна или выходят из игры (`open_app`, `start_desktop`, `desktop_on`, `arrange_windows`, `quit`,
`shell_exec`, `script_run`), — `async fn`: синхронная команда Tauri на Windows при создании окна вешает главный поток.
Окна из команд терминала (`edit`, `open`, `mail`…) открывает Rust (`apply_actions`), а из ответа терминалу такие действия
вычищаются, чтобы окно не открывалось дважды.

Сохранение: `%APPDATA%\top.blackwire.game\save.json` (весь мир в JSON; новая личность перезаписывает).

## Сборка

```powershell
cargo test --workspace --jobs 2
cargo build --release -p blackwire --jobs 2        # только exe → target\release\Blackwire.exe
cd app; cargo tauri build --bundles nsis -- --jobs 2   # exe + установщик target\release\bundle\nsis\
```
Готовые `Blackwire.exe` и `Blackwire-setup.exe` лежат в корне проекта (копируются после сборки вручную).
Интерфейс (`app/ui`) вшивается в exe при сборке — после правки HTML/CSS/JS нужна пересборка.

## Проверка

Окна смотрятся снимками, без нажатий клавиш. Ключи запуска (`app/src/checks.rs`):

```powershell
.\Blackwire.exe --new ghost --open "terminal:cd scripts; adder hello.adr; ls -l" --open mail --arrange grid
.\Blackwire.exe --load --monitor 1 --open editor:/home/ghost/scripts/scan.adr --open map --size 520x320 --arrange grid
.\Blackwire.exe --load --open browser:http://gate.hw/ --dump wins.json
```
`--new имя [--seed N]` — новая личность без пароля; `--load` — сохранённая игра; `--open приложение[:аргумент]` (для терминала
аргумент — первая команда); `--size ШxВ`; `--monitor N`; `--arrange grid|columns|rows|cascade`; `--no-desktop`;
`--dump файл` — список окон, мониторов и геометрии в JSON. Снимок монитора с учётом DPI — `tools\shot.ps1 -Out файл [-Screen N]`.
Проверено 25.10.2026: все девять окон на основном мониторе (1920×1080, 125 %) и на втором (3840×2160, 250 %), размеры
наименьший/средний/во весь экран, скрипты, ssh, сканирование, почта, страница приглашения hello-world, смена темы.

## Этапы

1. **Экосистема компьютера** (готово): окна, терминал, файлы, редактор, язык, браузер, почта, монитор, карта, настройки, справка;
   мир с организациями и подсетями; письмо hello-world и вход в скрытую сеть.
2. **Взлом** (готово): слабые места по версии служб, подбор пароля по словарю, повышение прав, прокси-цепочки, следы и
   подозрение, заметание следов. Устройство — `docs/HACK.md`, логика — крейт `blackwire-core`, модуль `src/hack/`:
   - `vuln` — классификация уязвимостей (таблица `net::services::VULNS`: служба/версия → доступ creds/shell/read/root/info);
   - `exploit` — доступ к удалённой машине (логин, оболочка, утечка файла); `crack` — подбор пароля по `~/wordlist.txt`;
   - `privesc` — повышение прав до root; `tracks` — подозрение (`heat`), след источника, чистка журналов; `proxy` — цепочка.
   - Команды терминала: `probe`, `exploit`, `crack`, `privesc`, `clearlogs`/`wipe`, `proxy`, `heat`, `creds` (группа «Взлом»).
   - Функции языка Adder: `net.vulns/exploit/crack/privesc/clear_logs/heat/owned/proxy` (см. `docs/ADDER.md`).
   - Подозрение растёт от действий над наблюдаемыми целями (центр безопасности, киберполиция, служба мониторинга, приманка);
     прокси-цепочка скрывает реальный адрес; `clearlogs` убирает улики; `heat` спадает со временем.
3. **Слежка** (готово): центры безопасности и киберполиция ведут расследование — модуль `core/src/hack/watch.rs`:
   - `Investigation` в `World` (стадия, прогресс 0..100, ведущий орган, следимые узлы, рейды, блокировка); `sweep` зовётся
     из `World::tick` раз в игровую секунду: дело растёт от улик (журналы с реальным адресом игрока) и подозрения, стихает без них.
   - Стадии: затишье → замечена активность → открыто дело → идёт пеленг → рейд. На переходах орган шлёт письмо-предупреждение
     (в почту игрока) и пишет в свой `/var/log/alerts.log`; на пике — **рейд**: обрывает цепочки подключений (`Game::poll_surveillance`
     возвращает сеансы домой), на ~2 минуты блокирует наступательные команды (`exploit/crack/ssh/scp`, и те же функции языка).
   - Команда `trace` — стадия, ведущий орган, прогресс, следимые узлы, отсчёт блокировки, подсказка (clearlogs); функция
     языка `net.watch()`. Счётчик слежки виден и через `heat`/улики. Связка с окнами — уведомление в `app/src/ticker.rs`.
4. **Задания hello-world** (готово): цепочка из 7 миссий — модуль `core/src/missions/`:
   - `MissionState` в `World` (цепочка `MissionRun`, активная, заработок); движок находит цели в мире по ролям (домашний ПК,
     банковское ядро, внутренняя машина за шлюзом, база больницы, публичный веб, узел наблюдателей), подставляет настоящие
     имена/адреса в брифинги, проверяет выполнение по состоянию мира (`check` из `World::tick`), платит награду (₵) и шлёт
     ответ группы со следующим заданием.
   - Цели проверяются по состоянию: прислать содержимое файла на `null@hw` (скан «Отправленных»), получить доступ (owned),
     поставить метку (файл с `hello-world`), замести следы (heat<15 и улик нет). Цепочка: вход → банк → прокси → больница →
     чистка → «голос» (defacement) → узел наблюдателей.
   - Доска `http://gate.hw/board` рисуется из состояния (`missions::board_html`); команды `missions`/`jobs`, `mission N`,
     `wallet` (группа «Задания»); функции языка `sys.money()`, `sys.missions()`. Уведомления — `app/src/ticker.rs`
     (`Game::poll_missions`). Содержание (тексты, голос группы) — `core/src/missions/data.rs`, легенда — `docs/STORY.md`.
5. **Деньги и долг** (готово): модуль `core/src/money/`:
   - `Finance` в `World` (кредит `debt`, ставка `rate_per_day`, кредитор — банк из сюжета, выплаты, `cleared`); `ensure_init`
     в `World::new` заводит долг (3000 ₵), `tick` набегают проценты. Оплата — `pay сумма|all` (`money::pay`): квитанция письмом,
     на нуле — кредит закрыт (письмо, флаг `debt_cleared`, уведомление).
   - Магазин (`money/shop.rs`): `shop`, `buy id`, `sell` (сбыть найденные логины по 50 ₵). Товары: большой словарь, карта
     провайдера, железо (сразу), «Туннель» (vpn — подозрение ×0.5), «Чистильщик» (scrubber — быстрее спад heat), «Руткит»
     (privesc всегда). Эффекты читают `Player.upgrades` в `hack::tracks` и `hack::privesc`.
   - Команды — `shell/cmds_money.rs` (группа «Деньги»: `wallet`, `debt`, `pay`, `shop`, `buy`, `sell`); страница `http://gate.hw/shop`
     (`money::shop_html` в `World::http`); функции языка `sys.money()`, `sys.debt()`. Доход: награды за задания + сбыт добычи.
6. **Концовка** (готово): модуль `core/src/ending.rs`. Победа — когда сошлись оба: пройдена вся цепочка заданий и закрыт
   кредит (`ending::check` из `World::tick`). Тогда группа шлёт последнее письмо, ставится флаг `won`, и оболочка
   авто-открывает окно финала (`app/ui/js/apps/finale.js`): логотип, заключительные слова, сводка пути (задания, деньги,
   взломы, пик подозрения, рейды) и кнопка «Остаться в системе». **Игра не кончается** — мир работает дальше, можно и
   дальше взламывать, торговать, исследовать. Команда `ending` показывает прогресс к свободе и, после победы, сводку;
   функция моста `ending_summary`.
   - **Экономика устойчива и ограничена**: доход — награды заданий (3250 ₵) плюс разовый сбыт каждого уникального логина
     (`World::add_found_cred` не даёт добыть один логин дважды — `Player.harvested`); расходы — долг (3000 ₵) и магазин
     (3600 ₵). Денег хватает на победу с запасом, но нажива пере-взломом исключена.
7. **Живой мир** (готово): модуль `core/src/life.rs` — раз в несколько игровых секунд случается мелкое событие (вход
   сотрудника, перезапуск службы, перезагрузка узла, городская новость); днём активность выше. Журналы меняются со временем,
   разведка видит свежие следы. Команда `news` — лента городских событий (`life::feed`, хранится в `World::life`).
8. **Подработки** (готово): модуль `core/src/gigs.rs` — всегда открыто несколько оплачиваемых заказов (прислать файл
   скупщику `broker@hw` или получить доступ к машине); выполнил — заплатили (`gigs::check` из `World::tick`) и появился новый.
   Ровный доход после сюжета. Команда `gigs` (группа «Задания»). Цели — публичные уязвимые машины (заказ на доступ не берёт
   уже взломанные).
9. **Новые механики взлома** (готово): `core/src/hack/{defense,tools,cipher}.rs`.
   - Файрвол (`defense::firewall_up` — у банков, SOC, киберполиции, правительства): закрывает узел для exploit/crack/ssh,
     пока не обойдёшь командой `firewall адрес` (шумно, с шансом). Приманка (`defense::is_trap`, honeypot): атака резко
     поднимает подозрение и подстёгивает расследование (`spring_trap`).
   - Кейлоггер (`tools::plant_keylog`): на захваченной машине со временем ловит чужой логин; команда `keylog [plant адрес]`.
   - Ботнет (`tools::botnet_add`): захваченные машины тихо приносят ₵; команда `botnet [add|remove адрес]`.
   - Шифр (`cipher`): `encrypt файл ключ` / `decrypt файл ключ`; на серверах баз лежит `/root/secret.enc`, ключ — в заметках.
10. **Ответный удар и защита** (готово): `core/src/hack/counter.rs`. При далёком расследовании (стадия ≥ «дело», traced,
   trapped) наблюдатели бьют в ответ по машине игрока: подсаживают закладки (`/tmp/.sysN`: маяк тянет следствие, майнер крадёт
   ₵, чёрный ход пускает их мимо файрвола) или штрафуют (суд списывает ₵). Защита: `shield on` (свой файрвол отражает атаки),
   `implants` (найти закладки), `clean` (вычистить). `tick` из `World::tick`, уведомления через `Game::poll_defense`.
11. **Хакерский маркет** (готово): `core/src/market.rs` — в сети hw (`gate.hw/market`, `market.hw`) за ₵ покупаются готовые
   скрипты на Adder (сканер, обходчик, автоподбор, чистильщик, сборщик, вербовщик); купил — лёг в `~/scripts`, запуск `adder`.
   Команда `market [buy id]` (группа «Деньги»). Скрипты — валидный Adder (проверяется тестом). Поддерживает цикл: заработал →
   купил инструмент → взломал больше.
12. **Своя база** (готово): `core/src/base.rs`. Команда `rent` арендует прокси-релей (500 ₵) — в мир добавляется настоящая
   машина-сервер с ssh, которой игрок владеет (root, пароль выдаётся); через неё ходят, чтобы прятать адрес. `base` — список
   релеев с логинами и плата (50 ₵/день, `tick` из `World::tick`); не хватило денег — релей забирают. `release адрес` —
   отказаться. Релеи появляются на карте сети. Группа команд «База».
13. **Достижения** (готово): `core/src/achievements.rs`. 14 отметок за ключевые дела (первый взлом, разведка, добытый логин,
   инструмент из маркета, кейлоггер, ботнет, своя база, подработки, пеленг, пережитый рейд, вычищенная закладка, деньги,
   закрытый долг, пройденный путь). Проверяются по состоянию мира в `World::tick`, открытое не пропадает и переживает
   сохранение. Команда `achievements` (и `ach`) — список открытых и закрытых; уведомление через `Game::poll_achievement`.
14. **Сохранения-слоты** (готово): помимо постоянного автосохранения (`save.json`) игрок делает именованные снимки.
   Файлы — `slots/<имя>.json` в папке данных; логика в `app/src/state.rs` (`save_slot`/`load_slot_world`/`delete_slot`/
   `list_slots`), команды Tauri `save_slots`/`save_to_slot`/`load_slot`/`delete_slot` в `app/src/cmd_game.rs`. В настройках —
   раздел «Сохранения»: «Новый слот», а у каждого слота кнопки «Загрузить», «Перезаписать», удалить (`app/ui/js/apps/settings.js`).
15. **Редактор сценариев** (готово): `core/src/scenarios.rs` + окно `app/ui/js/apps/scenario.js`. Игрок сам задаёт задание
   (цель — доступ к узлу / прислать текст с нужной строкой / накопить ₵ — описание и награда), сохраняет файлом
   (`scenarios/<имя>.json`) и запускает. Проверка выполнения — в `World::tick` (`scenarios::check`), награда и уведомление
   через `Game::poll_scenario`. Команды Tauri `scenario_*` (`app/src/cmd_game.rs`, файлы — `app/src/state.rs`), терминальная
   `scenario` показывает активный. Окно — в доке «Редактор сценариев».
16. **Сетевая игра** (готово): `app/src/netplay.rs`. Хост открывает порт (TCP), остальные подключаются по адресу — локальный
   адрес даёт игру по локалке, публичный (с пробросом порта) — через интернет (один и тот же TCP). Хост — ведущий (хаб):
   держит общую картину (ростер, прогресс, взятые цели) и рассылает её всем построчным JSON. Режимы: **дуэль** (вдвоём —
   кто первым получит доступ к узлу-призу) и **команда** (co-op — общий список целей, побеждает команда, взяв все). Партия
   идёт в обычном мире из общего зерна (сеть одинакова у всех); часы мира (`ticker::pump`) считают прогресс игрока по целям и
   шлют хосту. Команды `net_host`/`net_join`/`net_start`/`net_status`/`net_leave`; окно «Сетевая игра» (`app/ui/js/apps/duel.js`):
   лобби (создать/подключиться), ростер с полосами прогресса, итог. Проверка: `--duel host[:team]` / `--duel join:адрес` в
   `checks.rs` — поднял два экземпляра на 127.0.0.1, рукопожатие и ростер синхронизируются в обе стороны.
17. **Прозрачность окон** (готово): настройка `window_opacity` в `Settings` (ядро). Ползунок «Прозрачность окон» в
   «Настройках» (раздел «Вид») меняет её на лету для всех окон: `theme.js` ставит `--win-opacity`, фон `.win` в `win.css` —
   `rgba(var(--bg-rgb), var(--win-opacity))`, так что сквозь окна виден рабочий стол.
18. **Дальше**: по плану всё сделано. Осталось собрать установщик один раз в конце
   (`cd app; cargo tauri build --bundles nsis -- --jobs 2`).

## SDK плагинов Adder (API 1)

Плагины загружаются из `plugins` папки профиля. Окно «Плагины» на рабочем столе позволяет устанавливать примеры,
включать/выключать пакеты и запускать команды/собственные окна. Руководства: `docs/SDK.md`, `docs/GAME.md`,
скомпилированная справка `Blackwire.chm`. Они также доступны из окна справки игры.

Код: `core/src/plugins/` (загрузчик, хост Adder, создание контента, каталоги, таймеры, окна, события, проверка мира,
сетевые сообщения); `core/src/bin/plugin-check.rs` — проверка на настоящем игровом ядре.
`app/src/cmd_plugins.rs` — команды интерфейса; `app/ui/js/apps/plugins.js`, `plugin_panel.js` — окна.
Устройства получили `device_type` и `custom_vulns`; штатные разведка/эксплойты используют добавленные уязвимости.
Магазин, маркет, достижения и доска читают расширяемые каталоги. Состояние пакетов находится в `World.plugins`.

Примеры и схемы объектов: `sdk/examples`, `sdk/schema`. Проверка:

```text
cargo run -p blackwire-core --bin plugin-check -- sdk/examples --command district_create --command lab_create --ticks 65
cargo test --workspace --jobs 2
```

Для проверки окон без изменения основного сохранения: `Blackwire.exe --data-dir АБСОЛЮТНАЯ_ПАПКА --new sdk_test --open plugins`.
Плагин создаёт контент любых существующих подсистем через Adder и проверенные изменения модели; новые нативные инструкции
и графические примитивы относятся к коду самого движка. Обмен плагинов в сетевой партии не передаёт автоматически исходники
и весь мир: у участников должны быть совместимые пакеты.
