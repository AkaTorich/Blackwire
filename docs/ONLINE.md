# Онлайн — общий мир

В онлайне все игроки живут в одной сети Blackwire. Организации, банки, больницы, шлюзы и сайты `.hw` — общие: что один игрок изменил на машине, увидят остальные. У каждого свой компьютер (`имя-pc`) и роутер (`имя-router`) — такие же машины общей сети, как остальные.

Всё, ради чего играют, остаётся у каждого своим: цепочка заданий hello-world, долг банку, подработки, маркет, база, подозрение и расследование, достижения, концовка.

## Как войти

1. На экране входа — «Играть онлайн».
2. Адрес сервера (по умолчанию `game.globthe.top`), имя и пароль (от 6 знаков).
3. Первый раз — «Новая личность на сервере», потом — «Войти».

Пароль учётной записи хранится на сервере только в виде солёного хеша. Пароль своего игрового компьютера сервер выдаёт сам — он в заметках (`notes`), с паролем учётной записи не совпадает.

Своя одиночная игра в онлайне не трогается: её сохранение не пишется, слоты сохранений и прежняя «Сетевая игра» вдвоём в онлайне недоступны. Мир и прогресс хранит сервер.

## Что в онлайне

| Что | Как |
| --- | --- |
| Время | идёт на сервере; личный ход (проценты долга, спад подозрения, проверка заданий) — пока игрок в сети |
| Терминал, файлы, почта, карта, браузер, скрипты Adder | выполняются на сервере от лица игрока; окна — свои, на твоём экране |
| Чат игроков | окно «Чат игроков» в доке: кто в сети и общий разговор |
| Вход с другого места | прежнее подключение закрывается |
| Скрипты | до 6 одновременно; при выходе из сети останавливаются |

## Свой сервер

Сервер — отдельная программа `blackwire-server` без окон (Linux-служба).

```sh
blackwire-server --port 7777 --data ./data --cert fullchain.pem --key privkey.pem
```

| Ключ | Что делает |
| --- | --- |
| `--port N` | порт (по умолчанию 7777) |
| `--bind АДРЕС` | на каком адресе слушать (0.0.0.0) |
| `--data ПАПКА` | мир (`world.json`) и игроки (`players.json`), пишутся раз в минуту |
| `--cert`, `--key` | сертификат TLS; перечитывается сам, когда файл обновился |
| `--seed N` | зерно нового мира (только при первом запуске) |
| `--lang ru\|en` | язык общего мира |
| `--plugins ПАПКА` | плагины для сервера |
| `--max-accounts N`, `--max-scripts N` | пределы учётных записей и скриптов игрока |

Без `--cert/--key` связь идёт без шифрования — тогда в игре адрес пишется так: `tcp://192.168.0.5:7777` (для своей локальной сети).

Установка на Linux: собрать `bash tools/server/build-server-linux.sh` (статический бинарник, идёт на любом x86_64 Linux) и на сервере от root запустить `bash install.sh домен порт` из папки `server/deploy` — он заведёт пользователя `blackwire`, службу `blackwire-server`, копию сертификата сайта и ежедневное её обновление.

## Устройство

| Что | Где |
| --- | --- |
| Часть мира игрока и подстановка его в общий мир | `core/src/mmo.rs` (`PlayerCtx`, `World::mmo_new`, `mmo_add_player`, `Game::swap_player`) |
| Связь: строки JSON поверх TLS или TCP | крейт `wire/` |
| Сервер: учётные записи, команды, скрипты, часы, чат | крейт `server/` (`hub.rs`, `api.rs`, `scripts.rs`, `tick.rs`, `conn.rs`, `accounts.rs`) |
| Онлайн в игре: вход, пересылка команд, события сервера | `app/src/online.rs`; в окнах — `BW.online` и `REMOTE` в `app/ui/js/bridge.js` |
| Карточка «Онлайн» на экране входа | `app/ui/js/apps/login.js` |
| Чат игроков | `app/ui/js/apps/chat.js`, `app/ui/css/apps/chat.css` |
| Установка на сервер | `server/deploy/` (служба, `install.sh`), сборка — `tools/server/build-server-linux.sh` |
| Проверка | `core/tests/mmo.rs`; живой сервер — `tools/online-smoke.ps1` (без шифрования) и `cargo run -p blackwire-wire --example probe -- адрес` (TLS, как игра, без учётной записи); игра — ключ `--online "адрес\|имя\|пароль[\|new]"` |

Почему так: вся логика игры написана для «игрока» и его компьютера `machines[0]`. Сервер перед действием игрока подставляет его часть в общий мир и меняет местами его компьютер с заглушкой на месте 0, после действия — возвращает. Поэтому одиночные механики (взлом, слежка, задания, деньги) работают в онлайне без переделки, а номера машин всегда совпадают с их местом в списке.
