Начало и сохранения

В новой игре создай личность и, при необходимости, пароль. Загрузи существующую игру через экран входа. Основное сохранение находится в %APPDATA%\top.blackwire.game\save.json. Именованные слоты дают отдельные снимки. Перед экспериментами с плагином сделай слот: созданный им контент сохраняется внутри мира.

Мир строится из зерна; одинаковое зерно создаёт одинаковую исходную сеть. Игровое время идёт, пока приложение работает. Раз в минуту выполняется автосохранение. При выходе через игру выполняется сохранение; принудительное завершение Windows не заменяет его.

Для отдельного тестового профиля разработчик может запускать игру с --data-dir абсолютная-папка. Тогда сохранения, слоты, сценарии и плагины этого запуска находятся в указанной папке. Этот параметр удобен для проверки SDK без изменения своего прохождения.
