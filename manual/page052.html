Пример

# scan.adr — найти машины с открытым ssh
targets = sys.args[1:]
if not targets:
    print("Использование: scan.adr ip [ip ...]")
    exit(1)

for ip in targets:
    ms = net.ping(ip)
    if ms == null:
        print(f"{ip:16} недоступен")
        continue
    ports = net.scan(ip)
    open_ssh = [p for p in ports if p["port"] == 22]   # генераторы списков поддерживаются
    mark = "ssh" if open_ssh else "---"
    print(f"{ip:16} {ms:4} мс  {mark}  {len(ports)} портов")

Поддерживаются генераторы списков [выражение for x in xs if условие] и словарей {k: v for ...}. Форматирование в f-строках: {x:16} ширина, {x:>8} вправо, {x:.2f} знаки, {x:04} нули.

Объекты взлома

net.access(handle, method, ...args) обращается к выданному эксплоитом объекту. Список методов приходит в результате net.exploit. Объект действует в одном сеансе 300 игровых секунд. Частичный объект не выдаёт терминал. Полные параметры результатов, условия и примеры описаны в SDK.md, раздел «Результаты взлома и условия».
