Терминал и сеансы

Каждый терминал имеет текущую машину, пользователя, папку и цепочку подключений. При подключении ssh текущая машина меняется; exit возвращает на предыдущую, а на своей машине закрывает терминал.

Примеры:

pwd
ls -la
cat readme.txt
cd scripts
adder hello.adr
help ssh

Оболочка поддерживает кавычки, переменные окружения, псевдонимы, подстановку имён файлов, конвейеры и перенаправления. Например, cat файл | grep строка отбирает нужные строки, echo текст > файл записывает текст. Tab помогает дополнять имена. История сохраняется для текущего сеанса.

Обычные команды описаны в отдельном разделе «Команды терминала»: он сформирован непосредственно движком. Команды плагинов API 1 выполняются отдельно, без конвейера и перенаправления.
