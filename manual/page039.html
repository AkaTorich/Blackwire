Ошибки и границы API

Ошибка останавливает этот плагин; движок продолжает работать. Изменения мира, сеансов, очереди UI, запланированных скриптов и сетевого исходящего буфера текущего обработчика откатываются. Ранее успешно созданный контент остаётся. Включение заново или «Перечитать» повторяет on_load.

На обработчик выделено 50000 шагов интерпретатора; остановка не ловится try/except. Дополнительно проверяется время около 500 мс между периодическими проверками. Это кооперативные ограничения, а не отдельный процесс с жёсткой квотой памяти; крупные операции разбивай на таймеры и используй доверенные пакеты. input не блокирует игру — он выдаёт ошибку. sleep прерывает обработчик при следующей проверке; для задержек нужен таймер.

Размер entry и одного ресурса — до 256 КБ; объединённого исходника до 1 МБ, текстовых assets до 2 МБ; до 128 пакетов и 4096 устройств. Вывод команды ограничен 100 строками по 4096 символов.

В API 1 зарегистрированные команды плагинов запускаются отдельной командой, без конвейеров и перенаправления. Внутри плагина shell.exec работает с обычными возможностями встроенной оболочки. Вложенный синхронный вызов команды другого плагина не поддерживается. Для обмена общим контентом используй мир, зависимости и события.
