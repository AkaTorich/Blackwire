Встроенные функции

print(*args, sep=" ", end="") — печатает строку (каждый вызов — отдельная строка в терминале). input(prompt="") — читает строку от игрока. len, str, int, float, bool, list, dict, range(stop | start, stop[, step]), type(x) → "int", "str", … abs, min, max, sum, round(x[, n]), sorted(xs[, key][, reverse]), reversed, enumerate, zip, any, all chr, ord, hex, bin, oct, repr sleep(ms) — пауза, exit([code]). isinstance(x, "str") — проверка типа по имени.

Методы строк: upper lower strip lstrip rstrip split(sep=None) join replace find count startswith endswith isdigit isalpha isspace format(…) center(n) ljust(n) rjust(n) zfill(n) encode_hex decode_hex. Методы списков: append pop([i]) insert remove index count sort(key=None, reverse=False) reverse clear extend copy. Методы словарей: keys values items get(k[, default]) pop(k) has(k) clear copy update(other).

Модули без обращения к миру (есть всегда):

  • math: sqrt floor ceil sin cos tan atan2 log log2 log10 pow pi e
  • json: loads(str), dumps(value[, indent])
  • time: now() — игровое время в секундах, format(ts[, fmt]) — строка даты, ms() — миллисекунды реального времени
  • random: random(), randint(a, b), choice(list), shuffle(list), seed(n)
