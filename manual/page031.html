Основные функции

Все plugin.* ниже вызываются только из плагина. JSON-значения превращаются в обычные словари, списки, строки, числа и null Adder.

ВызовРезультат / действие
plugin.id()id текущего плагина
plugin.event()словарь текущего события
plugin.get(key, default=null)значение своего сохранённого ключа
plugin.set(key, value)сохранить значение; ключ до 128 символов, данные одного плагина до 64 КБ
plugin.asset(path)строка объявленного текстового ресурса
plugin.world() / plugin.world("overview")полное состояние мира / облегчённые данные для отчётов
plugin.apply(patch)атомарно заменить указанные разделы игрового состояния после проверки
plugin.random(lo, hi)целое из [lo, hi), генератор мира; границы в пределах ±10^9

Пример изменения экономики:

world = plugin.world()
world["finance"]["rate_per_day"] = 1.0
plugin.apply({"finance": world["finance"]})

apply принимает разделы machines, orgs, player, missions, finance, ending, life, gigs, market, base, achievements, scenarios, investigation, fw_down, keyloggers, botnet, botnet_mined, defense, down_until. Несколько разделов можно изменить одним вызовом, например одновременно машины и организации. Структура — та же, что в plugin.world(); примеры реальных объектов лежат в sdk/schema.

Движок проверяет типы, идентификаторы, ссылки, порты, адреса и маршруты. Нельзя удалить существующую машину/организацию, подменить личность игрока, удалить пользователя активного сеанса или создать цикл маршрутизаторов. Чтобы убрать устройство из работы, установи up=false. Часы, внутренний генератор, очереди и чужие данные плагинов через apply не заменяются.
