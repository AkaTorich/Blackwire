Проверка без окон

plugin-check.exe использует настоящее ядро Blackwire и создаёт отдельный тестовый мир с seed=42 и игроком sdk_test. Сохранения игрока не читает и не меняет.

plugin-check.exe sdk\examples --command district_create --command lab_create --ticks 65
plugin-check.exe папка-плагинов --command "команда аргументы" --ticks 10

Можно передать папку одного пакета с plugin.json или родительский каталог, каждая подпапка которого рассматривается как пакет. Опции идут после пути; --command можно повторять, --ticks допускает до 3600 шагов. --dump-world путь.json записывает тестовый мир; --dump-shell путь.md записывает справку реальных команд движка. Ошибка манифеста, обработчика или команды даёт ненулевой код завершения.

Для разработки из исходников:

cargo run -p blackwire-core --bin plugin-check -- sdk/examples --command district_create --ticks 65
cargo test -p blackwire-core plugins::tests
cargo test --workspace --jobs 2

Adder-check остаётся проверкой обычных скриптов языка. Для плагинов обязательно используй plugin-check: он вызывает реальные обработчики, проверяет API и видит настоящий мир. Одна проверка синтаксиса не доказывает работоспособность плагина.
