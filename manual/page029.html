Разрешения

РазрешениеВозможности
без разрешенийсвоё хранилище plugin.get/set, данные события, объявленные assets
contentсоздание/изменение игрового мира, типов устройств, уязвимостей, каталогов, заданий, окон, таймеров
sysигровые sys-функции: сведения, уведомления, открытие приложений; sys.kill в обработчике запрещён
fsобычные операции с виртуальными файлами в правах текущего игрового сеанса
netобычные игровые сетевые действия в правах текущего игрового сеанса
shellкоманды игровой оболочки через shell.exec; это также даёт доступ к механикам, реализованным командами
timeигровые вызовы хоста time.now
networkотправка и приём сообщений через уже подключённую сетевую партию игры

content — авторские полномочия над игровым миром. Это существенно шире прав обычного персонажа. net означает вымышленную сеть игры, network — канал установленной многопользовательской партии. Через SDK нет API чтения произвольных файлов Windows или запуска команд Windows.
