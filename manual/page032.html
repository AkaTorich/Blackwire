Типы устройств

ВызовНазначение
plugin.template(base_kind)готовый шаблон настоящего генератора игры
plugin.device_type(key, template)зарегистрировать собственный тип; возвращает plugin_id:key
plugin.spawn(type_id, properties)создать экземпляр; возвращает новый числовой id
plugin.machine(id)копия одной машины
plugin.update_machine(id, properties)частичное изменение машины с проверкой связей
plugin.user(id, name, password, admin=false)добавить игровую учётную запись и домашнюю папку
plugin.write(id, path, text)авторская запись в виртуальный файл; создаёт родительские папки

Базовые виды: player, home_pc, router, gateway, server, workstation, database, file_server, mail, web, camera, badge, atm, medical_device, dns, isp, honeypot.

Собственный тип — отдельный device_type с любым содержимым на основе базового поведения. Например, датчик, промышленный контроллер или спутниковый модем получают своё имя типа, ОС, оборудование, службы, файлы, пользователей и уязвимости. Особое поведение реализуется Adder-обработчиками. Новые нативные графические примитивы или инструкции интерпретатора требуют изменения самого движка.

def load(event):
    template = plugin.template("camera")
    template["os"] = "SensorOS 1.0"
    template["org"] = null
    template["router"] = null
    template["services"] = [{"port": 9000, "name": "sensor", "version": "1.0", "running": true, "banner": "Sensor control", "pages": []}]
    plugin.device_type("sensor", template)

def create(event):
    mid = plugin.spawn("my_plugin:sensor", {"hostname": "sensor-1", "ip": "198.18.10.1", "lan_ip": null, "domain": null, "up": true})
    plugin.user(mid, "operator", "sensor123", false)
    plugin.write(mid, "/etc/sensor/config.txt", "mode=normal\n")

id выдаётся автоматически, hostname и IP должны быть уникальны. Для внутреннего устройства укажи lan_ip, router, организацию и маршрут. Добавь id в player.known_machines, если оно должно сразу появиться на карте. Строка device_type отображается в карточке карты и neofetch; прочие правила поведения продолжают учитывать базовый kind.
