Службы, сайты, организации и почта

ВызовФормат
plugin.service(machine, spec)port, name, version, running, banner, pages; заменяет службу на этом порту
plugin.page(machine, port, spec)path, title, html; добавляет/заменяет страницу существующей службы
plugin.org(spec)name, kind, domain, gateway, subnet, members, description; id выдаётся автоматически
plugin.mail(machine, spec)from, subject, body, необязательный to; входящее письмо на указанной машине
plugin.log(machine, kind, text)login, login_failed, logout, exec, file_change, service, net, warn
plugin.news(text)новость в обычной городской ленте

Создавай сначала машины без организации, затем организацию с их id в members. plugin.org обновляет поле org у перечисленных машин. Маршрутизация задаётся router и lan_ip. Вид организации берётся из штатных corporation, bank, hospital, security_center, cyber_police, isp, university, hosting, government, media, shop, home, honeypot, underground.

Сайт открывается настоящим игровым браузером. HTML страницы проходит через существующий рендерер браузера игры; это контент виртуальной сети. Для собственных интерактивных инструментов используй окна плагина.
