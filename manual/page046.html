Adder — язык скриптов Blackwire

Файлы *.adr. Запуск из терминала: adder имя.adr [аргументы] или просто ./имя.adr, если файл исполняемый. Блоки задаются отступами (4 пробела или таб — главное, одинаково внутри файла). Комментарий — # до конца строки. Строка заканчивается оператором; внутри незакрытых скобок ( [ { переносы строк не считаются.
