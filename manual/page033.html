Задания и сценарии

plugin.quest(key, {title, objective, reward}) создаёт независимое задание плагина. Возвращает plugin_id:key. Повторная регистрация не сбрасывает выполнение. plugin.quest_complete(id) начисляет награду один раз и возвращает true при первом выполнении, false при повторе. Условия может проверять любой Adder-код: число устройств, конкретный файл, состояние службы, покупка, таймер, письмо, комбинация действий. Задания видны в missions и на gate.hw/board.

plugin.gig(spec) добавляет настоящую подработку: title, objective, reward, goal. Поддерживаются штатные цели {"Own":{"target":42}} и {"Deliver":{"target":42,"path":"/srv/data.txt","needle":"метка"}}. Id выдаётся автоматически.

plugin.scenario(spec) запускает сценарий редактора: name, brief, goal, reward. Штатные условия: {"OwnHost":{"host":"server-name"}}, {"Deliver":{"needle":"метка"}}, {"Money":{"amount":1000}}. Одновременно активен один такой сценарий; собственные quest могут работать параллельно.

Сюжетную цепочку можно расширять через раздел missions в apply. Там используются реальные MissionRun и Goal: ReadDeliver, Own, Plant, CoverTracks. Меняй согласованно active и status. Для независимых дополнений предпочтительнее quest, чтобы не менять условие завершения основной истории.
