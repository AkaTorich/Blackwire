Первый плагин

Папка my_counter:

{
  "id": "my_counter",
  "name": "Мой счётчик",
  "version": "1.0.0",
  "api": 1,
  "entry": "main.adr",
  "events": {"on_tick": "tick"},
  "commands": {"counter_show": "show"}
}

Файл main.adr:

def tick(event):
    plugin.set("ticks", plugin.get("ticks", 0) + 1)

def show(event):
    print("Тактов мира:", plugin.get("ticks", 0))

Нажми «Перечитать», затем counter_show. Значение сохраняется вместе с игрой.
