События

СобытиеКогда и что передаётся
on_loadзагрузка, перечитывание или включение пакета; пустой словарь
on_tickвызов Game.tick; dt_ms — прошедшие миллисекунды
on_commandзавершение встроенной команды игрока; line, session
on_hackуспешный удалённый или локальный игровой взлом; target, target_host, vuln (объект; имя в vuln["name"]), outcome, source_ip, monitored, heat_added
on_mailновое входящее письмо после шага мира: direction=inbox, mail; отправка через Game.mail_send: direction=sent, to, subject, body
on_mission_doneпродвижение сюжетной цепочки; before, active
on_gig_doneизменение числа выполненных подработок; before, done
on_purchaseпокупка; catalog=shop/market, id
on_achievementоткрыто достижение; id
on_investigationсмена стадии слежки; before, stage, progress
on_scenario_doneзавершён активный сценарий; scenario
on_worldизменилось число машин или организаций; machines, orgs
on_fileизменение через редактор/файловое окно или файловый API Adder; operation и сведения об операции
on_uiкнопка собственного окна; window, action, values
on_networkпакет установленной партии; plugin, channel, data, from
on_saveперед сохранением основного профиля
on_unloadвыключение пакета или выход через игровую команду quit
custom.имяадресное событие таймера этого плагина; timer, data

События изменения состояния формируются после действия оболочки, API Adder и шага мира. Изменения, которые делает обработчик, не вызывают синхронный рекурсивный запуск другого обработчика. Проверки собственных произвольных условий удобно делать в on_tick или по таймеру. Прямое закрытие процесса Windows не гарантирует on_unload; важные данные сохраняй по ходу работы.
