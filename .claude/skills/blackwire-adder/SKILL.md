# Скрипты Adder для Blackwire

Adder — язык скриптов игры Blackwire: синтаксис как у Python (отступы, `def`, `for`, f-строки,
генераторы списков), но мир скрипт видит только через четыре игровых модуля: `sys`, `fs`, `net`, `shell`.
Всё, что делает скрипт, происходит внутри вымышленной сети игры.

## Что лежит рядом

- `reference/ADDER.md` — полный язык: типы, операторы, встроенные функции, методы строк/списков/словарей,
  модули `math json time random` и все игровые функции с тем, что они возвращают. **Читай перед первым скриптом.**
- `reference/COMMANDS.md` — команды терминала игры; скрипт вызывает их через `shell.exec("строка")` → `{out, ok}`.
  Через них доступно то, чего нет в модулях: кейлоггер, ботнет, файрвол, шифр, защита, база, задания, маркет.
- `examples/*.adr` — шесть настоящих скриптов из маркета игры (проверены). Образцы стиля и приёмов.
- `bin/adder-check.exe` — проверка: `adder-check файл.adr` (синтаксис) и `adder-check файл.adr --run [арг…]`
  (плюс пробный запуск: игровые функции отвечают пустыми заготовками, неизвестная функция — ошибка).

## Порядок работы

1. Пойми задачу: что скрипт принимает (`sys.args[1:]`), что делает, что печатает. Если неясно главное — спроси коротко.
2. Пиши только тем, что есть в `reference/ADDER.md`. Не выдумывай функции и модули: нет `import`, классов, `with`,
   `open()`, `os`, `requests`. Игровое — только `sys.* fs.* net.* shell.*`, остальное — через `shell.exec`.
3. Стиль игры:
   - первой строкой — комментарий `# имя.adr — что делает`;
   - без аргументов — печатать строку «Использование: …» и `exit(1)`;
   - сетевые и файловые вызовы оборачивать в `try/except as e` — они бросают исключения (нет связи, нет прав);
   - `net.connect` переносит сеанс на ту машину — после работы `net.disconnect()`;
   - для слежки помнить о `net.heat()` и `net.watch()`; шумные действия — после `net.proxy()`;
   - печать короткими строками, выравнивание f-строками `{x:16}`, `{x:>6}`.
4. Сохрани скрипт в файл `.adr` (рабочая папка или куда попросили) и проверь:
   ```
   .claude/skills/blackwire-adder/bin/adder-check.exe путь/скрипт.adr --run 10.0.0.5
   ```
   Исправляй, пока не будет `синтаксис: OK` и `пробный запуск: OK`. Пробный запуск не знает настоящий мир
   (списки пустые, логины не подбираются) — он ловит опечатки в именах функций и ошибки исполнения, а не логику.
5. Отдай скрипт целиком и скажи, как запустить в игре: открыть редактор (`edit ~/scripts/имя.adr`), вставить,
   сохранить, затем в терминале `adder ~/scripts/имя.adr аргументы` (или `chmod +x` и `./имя.adr`).

## Если приносят сломанный скрипт

Сохрани его в файл, прогони `adder-check` — он назовёт строку и причину. Почини, прогони снова, объясни, что было не так.

## Если `adder-check` нет (Linux, macOS) или он устарел

Готовый `bin/adder-check.exe` — только для Windows. Исходник утилиты — в `checker/` (Rust, зависит от крейта
языка `lang/` этого репозитория). Сборка: `cargo build --release` в папке `checker`, затем
`checker/target/release/adder-check` (на Windows — `.exe`) положить в `bin/`.
