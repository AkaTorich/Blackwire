# Команды терминала Blackwire

Оболочка понимает конвейеры (`a | b`), перенаправления (`>`, `>>`, `2>`, `<`), разделители (`;`, `&&`, `||`), переменные (`$ИМЯ`, `${ИМЯ}`), домашнюю папку (`~`) и подстановку `*`/`?` в именах файлов. У каждой команды есть `--help`.

|---|---|---|
| `ls` | `ls [-l] [-a] [-h] [путь…]` | список файлов |
