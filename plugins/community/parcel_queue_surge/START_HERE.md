# Переполнение очереди посылок

В маршрутизаторе посылок копятся отложенные пикапы на фоне наплыва.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `parcel_queue_surge_open` или нажми «Старт».
3. В терминале запусти `parcel_queue_surge_start`.
4. Прочитай письмо «Переполнение очереди посылок: первая зацепка» в игровой почте.
5. Открой `http://198.22.97.1/` в игровом браузере и запусти `probe 198.22.97.1`.
6. Поймать запись инцидента и пройти по его таймлайну.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `parcel_queue`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `parcel_queue_surge_status` показывает прогресс без сброса.
- Награда: 148 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s parcel_queue_surge:records_entry 198.22.97.1`

Прочитай `/srv/records/queue-depth.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: события. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
