# Панели управления лифтами

Служебная панель зафиксировала внеплановую остановку на закрытом этаже.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `elevator_control_panels_open` или нажми «Старт».
3. В терминале запусти `elevator_control_panels_start`.
4. Прочитай письмо «Панели управления лифтами: первая зацепка» в игровой почте.
5. Открой `http://198.22.14.1/` в игровом браузере и запусти `probe 198.22.14.1`.
6. Разобраться с контроллером и восстановить его рабочую запись.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `lift_service`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `elevator_control_panels_status` показывает прогресс без сброса.
- Награда: 112 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s elevator_control_panels:records_entry 198.22.14.1`

Прочитай `/srv/records/visits.log` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: устройства. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
