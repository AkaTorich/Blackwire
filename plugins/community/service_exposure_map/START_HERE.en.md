# Service Exposure Map

Inspect running services on discovered machines.

## Start here

1. Put this folder next to your other plugins and press **Reload**.
2. Run `service_exposure_map_open` to open the window, or `service_exposure_map_report` to print to the terminal.
3. **Refresh** re-reads the world; **Export report** writes a report to your in-game home folder (`reports/`).

There is no task — an empty report means no matching hosts or records have been scouted yet.

## Installation and persistence

Family: tools. The plugin folder never touches other saves; the result stays in the save even if the plugin is disabled.
