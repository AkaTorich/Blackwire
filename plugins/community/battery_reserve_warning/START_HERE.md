# Предупреждение о резерве батареи

Контроллер резервной батареи отчитывается о падающем заряде на учениях сети.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `battery_reserve_warning_open` или нажми «Старт».
3. В терминале запусти `battery_reserve_warning_start`.
4. Прочитай письмо «Предупреждение о резерве батареи: первая зацепка» в игровой почте.
5. Открой `http://198.22.98.1/` в игровом браузере и запусти `probe 198.22.98.1`.
6. Поймать запись инцидента и пройти по его таймлайну.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `battery_monitor`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `battery_reserve_warning_status` показывает прогресс без сброса.
- Награда: 156 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.98.1 battery_reserve_warning:records_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.98.1 battery_reserve_warning:records_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s battery_reserve_warning:records_entry 198.22.98.1`

Прочитай `/srv/records/reserve.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: события. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
