# Районный узел обмена трафиком

Скрытый партнёр подключён по давно устаревшему соглашению.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `community_internet_exchange_open` или нажми «Старт».
3. В терминале запусти `community_internet_exchange_start`.
4. Прочитай письмо «Районный узел обмена трафиком: первая зацепка» в игровой почте.
5. Открой `http://198.22.36.1/` в игровом браузере и запусти `probe 198.22.36.1`.
6. Пройти через шлюз и забрать внутренний архив.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `exchange_archive`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `community_internet_exchange_status` показывает прогресс без сброса.
- Награда: 240 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s community_internet_exchange:gateway_entry 198.22.36.1`

Прочитай `/srv/records/peering-register.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: сети. Организация: провайдер. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
