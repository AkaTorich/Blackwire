# Фантомные заказы доставки

Контейнеры выставили на адрес, за которым нет ни одного заказчика.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `ghost_shipping_orders_open` или нажми «Старт».
3. В терминале запусти `ghost_shipping_orders_start`.
4. Прочитай письмо «Фантомные заказы доставки: первая зацепка» в игровой почте.
5. Открой `http://198.22.45.1/` в игровом браузере и запусти `probe 198.22.45.1`.
6. Отследить обоих свидетелей и восстановить цепочку хранения.

## Подсказки

Механика взлома: regex_backtracking. Подсказки и параметры конкретного устройства даёт research.

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `shipping_store`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `ghost_shipping_orders_status` показывает прогресс без сброса.
- Награда: 210 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.45.1 ghost_shipping_orders:gateway_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.45.1 ghost_shipping_orders:gateway_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_regex_backtracking`.

`exploit -f ~/scripts/exp_regex_backtracking.adr -s ghost_shipping_orders:gateway_entry 198.22.45.1`

Прочитай `/srv/records/ghost-orders.csv` на последнем узле — там сохранённая запись.
