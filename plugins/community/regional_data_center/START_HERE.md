# Региональный ЦОД

В журналах стоек видно арендатора, которого нет в списке, но он занимает резервные мощности.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `regional_data_center_open` или нажми «Старт».
3. В терминале запусти `regional_data_center_start`.
4. Прочитай письмо «Региональный ЦОД: первая зацепка» в игровой почте.
5. Открой `http://198.22.27.1/` в игровом браузере и запусти `probe 198.22.27.1`.
6. Пройти через шлюз и забрать внутренний архив.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `tenant_archive`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `regional_data_center_status` показывает прогресс без сброса.
- Награда: 186 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s regional_data_center:gateway_entry 198.22.27.1`

Прочитай `/srv/records/rack-allocation.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: сети. Организация: хостинг. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
