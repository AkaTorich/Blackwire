# Сеть частной клиники

Частная клиника спрятала архив записей за забытым служебным шлюзом.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `private_clinic_network_open` или нажми «Старт».
3. В терминале запусти `private_clinic_network_start`.
4. Прочитай письмо «Сеть частной клиники: первая зацепка» в игровой почте.
5. Открой `http://198.22.21.1/` в игровом браузере и запусти `probe 198.22.21.1`.
6. Пройти через шлюз и забрать внутренний архив.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `patient_archive`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `private_clinic_network_status` показывает прогресс без сброса.
- Награда: 150 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s private_clinic_network:gateway_entry 198.22.21.1`

Прочитай `/srv/records/patient-audit.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: сети. Организация: больница. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
