# Подпольная радиостанция

Запись в эфир подменили, пока у пульта никого не было.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `underground_radio_station_open` или нажми «Старт».
3. В терминале запусти `underground_radio_station_start`.
4. Прочитай письмо «Подпольная радиостанция: первая зацепка» в игровой почте.
5. Открой `http://198.22.40.1/` в игровом браузере и запусти `probe 198.22.40.1`.
6. Пройти через шлюз и забрать внутренний архив.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `radio_archive`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `underground_radio_station_status` показывает прогресс без сброса.
- Награда: 264 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.40.1 underground_radio_station:gateway_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.40.1 underground_radio_station:gateway_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s underground_radio_station:gateway_entry 198.22.40.1`

Прочитай `/srv/records/broadcast-ledger.txt` на последнем узле — там сохранённая запись.

Семейство: сети. Организация: скрытая группа. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
