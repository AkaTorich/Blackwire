# Киоски оплаты в кафе

В чеке №184 возврат ушёл на уже выведенную из эксплуатации кассу.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `cafe_payment_kiosks_open` или нажми «Старт».
3. В терминале запусти `cafe_payment_kiosks_start`.
4. Прочитай письмо «Киоски оплаты в кафе: первая зацепка» в игровой почте.
5. Открой `http://198.22.8.1/` в игровом браузере и запусти `probe 198.22.8.1`.
6. Разобраться с контроллером и восстановить его рабочую запись.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `cafe_pay`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `cafe_payment_kiosks_status` показывает прогресс без сброса.
- Награда: 88 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.8.1 cafe_payment_kiosks:records_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.8.1 cafe_payment_kiosks:records_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s cafe_payment_kiosks:records_entry 198.22.8.1`

Прочитай `/srv/records/receipts.csv` на последнем узле — там сохранённая запись.

Семейство: устройства. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
