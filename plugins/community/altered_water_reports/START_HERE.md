# Подправленные отчёты по воде

Подписанные результаты лаборатории расходятся с цифрами на публичном табло.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `altered_water_reports_open` или нажми «Старт».
3. В терминале запусти `altered_water_reports_start`.
4. Прочитай письмо «Подправленные отчёты по воде: первая зацепка» в игровой почте.
5. Открой `http://198.22.44.1/` в игровом браузере и запусти `probe 198.22.44.1`.
6. Отследить обоих свидетелей и восстановить цепочку хранения.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `water_records`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `altered_water_reports_status` показывает прогресс без сброса.
- Награда: 205 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s altered_water_reports:gateway_entry 198.22.44.1`

Прочитай `/srv/records/sample-chain.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: расследования. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
