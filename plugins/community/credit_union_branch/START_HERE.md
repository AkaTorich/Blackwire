# Отделение кредитного союза

Во внутренней книге нашёлся кредит, одобренный уже после ухода подписанта.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `credit_union_branch_open` или нажми «Старт».
3. В терминале запусти `credit_union_branch_start`.
4. Прочитай письмо «Отделение кредитного союза: первая зацепка» в игровой почте.
5. Открой `http://198.22.25.1/` в игровом браузере и запусти `probe 198.22.25.1`.
6. Пройти через шлюз и забрать внутренний архив.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `loan_archive`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `credit_union_branch_status` показывает прогресс без сброса.
- Награда: 174 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s credit_union_branch:gateway_entry 198.22.25.1`

Прочитай `/srv/records/loan-ledger.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: сети. Организация: банк. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
