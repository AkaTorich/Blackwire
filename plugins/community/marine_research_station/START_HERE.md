# Морская исследовательская станция

Маршрут судна противоречит показаниям буёв, скачанных с их же сервера.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `marine_research_station_open` или нажми «Старт».
3. В терминале запусти `marine_research_station_start`.
4. Прочитай письмо «Морская исследовательская станция: первая зацепка» в игровой почте.
5. Открой `http://198.22.39.1/` в игровом браузере и запусти `probe 198.22.39.1`.
6. Пройти через шлюз и забрать внутренний архив.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `marine_archive`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `marine_research_station_status` показывает прогресс без сброса.
- Награда: 258 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s marine_research_station:gateway_entry 198.22.39.1`

Прочитай `/srv/records/buoy-survey.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: сети. Организация: университет. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
