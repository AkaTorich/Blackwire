# Подменённые строительные заявки

Поданная заявка отличается от редакции, которую хранит приёмная комиссия.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `swapped_construction_bids_open` или нажми «Старт».
3. В терминале запусти `swapped_construction_bids_start`.
4. Прочитай письмо «Подменённые строительные заявки: первая зацепка» в игровой почте.
5. Открой `http://198.22.57.1/` в игровом браузере и запусти `probe 198.22.57.1`.
6. Отследить обоих свидетелей и восстановить цепочку хранения.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `bid_store`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `swapped_construction_bids_status` показывает прогресс без сброса.
- Награда: 270 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.57.1 swapped_construction_bids:gateway_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.57.1 swapped_construction_bids:gateway_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s swapped_construction_bids:gateway_entry 198.22.57.1`

Прочитай `/srv/records/bid-history.csv` на последнем узле — там сохранённая запись.
