# Терминалы парковки

За место B17 списали дважды — надо сверить журнал транзакций терминала.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `parking_terminals_open` или нажми «Старт».
3. В терминале запусти `parking_terminals_start`.
4. Прочитай письмо «Терминалы парковки: первая зацепка» в игровой почте.
5. Открой `http://198.22.2.1/` в игровом браузере и запусти `probe 198.22.2.1`.
6. Разобраться с контроллером и восстановить его рабочую запись.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `parking_pay`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `parking_terminals_status` показывает прогресс без сброса.
- Награда: 64 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s parking_terminals:records_entry 198.22.2.1`

Прочитай `/srv/records/tickets.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: устройства. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
