# Сканеры штрихкодов на складе

Паллета CR-204 оказалась у погрузки без сканирования на выдачу.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `warehouse_barcode_scanners_open` или нажми «Старт».
3. В терминале запусти `warehouse_barcode_scanners_start`.
4. Прочитай письмо «Сканеры штрихкодов на складе: первая зацепка» в игровой почте.
5. Открой `http://198.22.6.1/` в игровом браузере и запусти `probe 198.22.6.1`.
6. Разобраться с контроллером и восстановить его рабочую запись.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `stock_sync`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `warehouse_barcode_scanners_status` показывает прогресс без сброса.
- Награда: 80 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.6.1 warehouse_barcode_scanners:records_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.6.1 warehouse_barcode_scanners:records_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s warehouse_barcode_scanners:records_entry 198.22.6.1`

Прочитай `/srv/records/scans.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: устройства. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
