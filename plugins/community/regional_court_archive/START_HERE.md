# Областной судебный архив

Опечатанное дело всплывает в указателе с подправленной датой передачи.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `regional_court_archive_open` или нажми «Старт».
3. В терминале запусти `regional_court_archive_start`.
4. Прочитай письмо «Областной судебный архив: первая зацепка» в игровой почте.
5. Открой `http://198.22.38.1/` в игровом браузере и запусти `probe 198.22.38.1`.
6. Пройти через шлюз и забрать внутренний архив.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `court_archive`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `regional_court_archive_status` показывает прогресс без сброса.
- Награда: 252 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.38.1 regional_court_archive:gateway_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.38.1 regional_court_archive:gateway_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s regional_court_archive:gateway_entry 198.22.38.1`

Прочитай `/srv/records/case-index.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: сети. Организация: ведомство. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
