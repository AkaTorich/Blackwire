# Heat Watch Tool

Report suspicion and investigation progress.

## Start here

Run `heat_watch_tool_open` or `heat_watch_tool_status` for instructions. The item is listed in the script market.

Purchase: `market buy heat_watch_tool:item` (45 credits).

Run the purchased tool with `adder ~/scripts/heat_watch.adr`.

## Installation and persistence

Copy this plugin folder into the directory opened by **Plugins → Open folder**, then Reload. It is independent of the other 99 plugins. Created game content remains in the save after disabling a plugin. Names, commands and addresses are unique within this pack.
