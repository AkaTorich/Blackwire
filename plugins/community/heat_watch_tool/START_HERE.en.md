# Heat Watch Tool

Report suspicion and investigation progress.

## Start here

1. Put this folder next to your other plugins and press **Reload**.
2. Buy the script with `market buy heat_watch_tool:item` — it appears in the market.
3. After buying, run it: `adder ~/scripts/heat_watch.adr`.

## Installation and persistence

Family: shops. The plugin folder never touches other saves; the result stays in the save even if the plugin is disabled.
