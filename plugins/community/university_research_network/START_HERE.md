# Сеть университетской кафедры

Грант лаборатории провели через заброшенный исследовательский проект.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `university_research_network_open` или нажми «Старт».
3. В терминале запусти `university_research_network_start`.
4. Прочитай письмо «Сеть университетской кафедры: первая зацепка» в игровой почте.
5. Открой `http://198.22.23.1/` в игровом браузере и запусти `probe 198.22.23.1`.
6. Пройти через шлюз и забрать внутренний архив.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `research_store`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `university_research_network_status` показывает прогресс без сброса.
- Награда: 162 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s university_research_network:gateway_entry 198.22.23.1`

Прочитай `/srv/records/grant-register.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: сети. Организация: университет. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
