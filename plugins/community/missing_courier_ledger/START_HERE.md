# Журнал пропавшего курьера

Курьер исчез между двумя складами; книга передач называет последнего приёмщика.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `missing_courier_ledger_open` или нажми «Старт».
3. В терминале запусти `missing_courier_ledger_start`.
4. Прочитай письмо «Журнал пропавшего курьера: первая зацепка» в игровой почте.
5. Открой `http://198.22.41.1/` в игровом браузере и запусти `probe 198.22.41.1`.
6. Отследить обоих свидетелей и восстановить цепочку хранения.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `courier_records`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `missing_courier_ledger_status` показывает прогресс без сброса.
- Награда: 190 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.41.1 missing_courier_ledger:gateway_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.41.1 missing_courier_ledger:gateway_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s missing_courier_ledger:gateway_entry 198.22.41.1`

Прочитай `/srv/records/handoff-ledger.csv` на последнем узле — там сохранённая запись.
