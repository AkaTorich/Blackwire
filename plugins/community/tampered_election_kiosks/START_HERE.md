# Подправленные киоски выборов

Вымышленный городской киоск отчитался о работах за учётку, которая давно закрыта.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `tampered_election_kiosks_open` или нажми «Старт».
3. В терминале запусти `tampered_election_kiosks_start`.
4. Прочитай письмо «Подправленные киоски выборов: первая зацепка» в игровой почте.
5. Открой `http://198.22.52.1/` в игровом браузере и запусти `probe 198.22.52.1`.
6. Отследить обоих свидетелей и восстановить цепочку хранения.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `kiosk_records`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `tampered_election_kiosks_status` показывает прогресс без сброса.
- Награда: 245 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.52.1 tampered_election_kiosks:gateway_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.52.1 tampered_election_kiosks:gateway_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s tampered_election_kiosks:gateway_entry 198.22.52.1`

Прочитай `/srv/records/maintenance-audit.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: расследования. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
