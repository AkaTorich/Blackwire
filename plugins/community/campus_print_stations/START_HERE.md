# Печать на кампусе

Экзаменационный материал под грифом остался в общей очереди печати.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `campus_print_stations_open` или нажми «Старт».
3. В терминале запусти `campus_print_stations_start`.
4. Прочитай письмо «Печать на кампусе: первая зацепка» в игровой почте.
5. Открой `http://198.22.18.1/` в игровом браузере и запусти `probe 198.22.18.1`.
6. Разобраться с контроллером и восстановить его рабочую запись.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `print_spool`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `campus_print_stations_status` показывает прогресс без сброса.
- Награда: 128 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.18.1 campus_print_stations:records_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.18.1 campus_print_stations:records_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s campus_print_stations:records_entry 198.22.18.1`

Прочитай `/srv/records/queue.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: устройства. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
