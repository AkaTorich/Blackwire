# Сеть независимой редакции

Редактору нужны исходники — публичный материал кто-то тихо подправил.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `independent_newsroom_open` или нажми «Старт».
3. В терминале запусти `independent_newsroom_start`.
4. Прочитай письмо «Сеть независимой редакции: первая зацепка» в игровой почте.
5. Открой `http://198.22.24.1/` в игровом браузере и запусти `probe 198.22.24.1`.
6. Пройти через шлюз и забрать внутренний архив.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `editorial_vault`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `independent_newsroom_status` показывает прогресс без сброса.
- Награда: 168 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s independent_newsroom:gateway_entry 198.22.24.1`

Прочитай `/srv/records/editorial-notes.txt` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: сети. Организация: СМИ. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
