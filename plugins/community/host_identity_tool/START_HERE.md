# Host Identity Tool

Report the current host, address and access level.

## Start here

Run `host_identity_tool_open` or `host_identity_tool_status` for instructions. The item is listed in the script market.

Purchase: `market buy host_identity_tool:item` (15 credits).

Run the purchased tool with `adder ~/scripts/host_identity.adr`.

## Installation and persistence

Copy this plugin folder into the directory opened by **Plugins → Open folder**, then Reload. It is independent of the other 99 plugins. Created game content remains in the save after disabling a plugin. Names, commands and addresses are unique within this pack.
