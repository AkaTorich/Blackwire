# Host Identity Tool

Report the current host, address and access level.

## Start here

1. Put this folder next to your other plugins and press **Reload**.
2. Buy the script with `market buy host_identity_tool:item` — it appears in the market.
3. After buying, run it: `adder ~/scripts/host_identity.adr`.

## Installation and persistence

Family: shops. The plugin folder never touches other saves; the result stays in the save even if the plugin is disabled.
