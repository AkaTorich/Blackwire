# Диспетчерская железной дороги

Грузовой маршрут переделали уже после того, как диспетчер сдал смену.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `railway_dispatch_network_open` или нажми «Старт».
3. В терминале запусти `railway_dispatch_network_start`.
4. Прочитай письмо «Диспетчерская железной дороги: первая зацепка» в игровой почте.
5. Открой `http://198.22.32.1/` в игровом браузере и запусти `probe 198.22.32.1`.
6. Пройти через шлюз и забрать внутренний архив.

## Подсказки

Механика взлома: use_after_free. Подсказки и параметры конкретного устройства даёт research.

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `rail_archive`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `railway_dispatch_network_status` показывает прогресс без сброса.
- Награда: 216 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.32.1 railway_dispatch_network:gateway_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.32.1 railway_dispatch_network:gateway_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_use_after_free`.

`exploit -f ~/scripts/exp_use_after_free.adr -s railway_dispatch_network:gateway_entry 198.22.32.1`

Прочитай `/srv/records/dispatch-orders.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: сети. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
