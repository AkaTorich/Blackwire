# Перенаправленная гуманитарная помощь

Посылки с помощью отметили как доставленные, не доведя до регионального склада.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `diverted_relief_supplies_open` или нажми «Старт».
3. В терминале запусти `diverted_relief_supplies_start`.
4. Прочитай письмо «Перенаправленная гуманитарная помощь: первая зацепка» в игровой почте.
5. Открой `http://198.22.50.1/` в игровом браузере и запусти `probe 198.22.50.1`.
6. Отследить обоих свидетелей и восстановить цепочку хранения.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `relief_archive`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `diverted_relief_supplies_status` показывает прогресс без сброса.
- Награда: 235 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s diverted_relief_supplies:gateway_entry 198.22.50.1`

Прочитай `/srv/records/relief-consignments.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: расследования. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
