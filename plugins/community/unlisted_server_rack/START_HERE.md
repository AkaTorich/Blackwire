# Безучётная серверная стойка

По расходу питания видно занятую стойку, которой нет в инвентарной описи.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `unlisted_server_rack_open` или нажми «Старт».
3. В терминале запусти `unlisted_server_rack_start`.
4. Прочитай письмо «Безучётная серверная стойка: первая зацепка» в игровой почте.
5. Открой `http://198.22.60.1/` в игровом браузере и запусти `probe 198.22.60.1`.
6. Отследить обоих свидетелей и восстановить цепочку хранения.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `rack_store`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `unlisted_server_rack_status` показывает прогресс без сброса.
- Награда: 285 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s unlisted_server_rack:gateway_entry 198.22.60.1`

Прочитай `/srv/records/capacity-report.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: расследования. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
