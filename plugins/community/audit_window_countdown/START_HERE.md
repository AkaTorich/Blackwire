# Отсчёт окна аудита

Временная служба аудита доступна только на короткое плановое окно.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `audit_window_countdown_open` или нажми «Старт».
3. В терминале запусти `audit_window_countdown_start`.
4. Прочитай письмо «Отсчёт окна аудита: первая зацепка» в игровой почте.
5. Открой `http://198.22.99.1/` в игровом браузере и запусти `probe 198.22.99.1`.
6. Поймать запись инцидента и пройти по его таймлайну.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `audit_window`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `audit_window_countdown_status` показывает прогресс без сброса.
- Награда: 164 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.99.1 audit_window_countdown:records_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.99.1 audit_window_countdown:records_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s audit_window_countdown:records_entry 198.22.99.1`

Прочитай `/srv/records/audit-window.txt` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: события. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
