# Directory Audit Tool

Inspect file ownership and permissions in the current directory.

## Start here

Run `directory_audit_tool_open` or `directory_audit_tool_status` for instructions. The item is listed in the script market.

Purchase: `market buy directory_audit_tool:item` (40 credits).

Run the purchased tool with `adder ~/scripts/directory_audit.adr`.

## Installation and persistence

Copy this plugin folder into the directory opened by **Plugins → Open folder**, then Reload. It is independent of the other 99 plugins. Created game content remains in the save after disabling a plugin. Names, commands and addresses are unique within this pack.
