# Инструмент: разбор каталога

Показывает владельцев, права и размеры файлов текущего каталога.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Купи скрипт командой `market buy directory_audit_tool:item` — он появится в маркете.
3. После покупки запусти его: `adder ~/scripts/directory_audit.adr`.

## Установка и память

Семейство: магазины. Папка плагина не трогает чужие сохранения; результат остаётся в сейве даже если плагин выключить.
