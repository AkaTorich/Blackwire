# Mission Checklist Tool

Print the active mission checklist.

## Start here

Run `mission_checklist_tool_open` or `mission_checklist_tool_status` for instructions. The item is listed in the script market.

Purchase: `market buy mission_checklist_tool:item` (30 credits).

Run the purchased tool with `adder ~/scripts/mission_checklist.adr`.

## Installation and persistence

Copy this plugin folder into the directory opened by **Plugins → Open folder**, then Reload. It is independent of the other 99 plugins. Created game content remains in the save after disabling a plugin. Names, commands and addresses are unique within this pack.
