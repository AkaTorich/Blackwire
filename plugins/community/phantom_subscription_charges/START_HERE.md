# Фантомные списания по подписке

С неактивных аккаунтов списывают за услугу, которой нет в прайсе.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `phantom_subscription_charges_open` или нажми «Старт».
3. В терминале запусти `phantom_subscription_charges_start`.
4. Прочитай письмо «Фантомные списания по подписке: первая зацепка» в игровой почте.
5. Открой `http://198.22.58.1/` в игровом браузере и запусти `probe 198.22.58.1`.
6. Отследить обоих свидетелей и восстановить цепочку хранения.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `billing_archive`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `phantom_subscription_charges_status` показывает прогресс без сброса.
- Награда: 275 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`exploit -s phantom_subscription_charges:gateway_entry 198.22.58.1`

Прочитай `/srv/records/subscription-ledger.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: расследования. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
