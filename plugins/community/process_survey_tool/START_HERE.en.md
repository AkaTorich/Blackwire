# Process Survey Tool

Print process ownership, CPU use and memory use.

## Start here

1. Put this folder next to your other plugins and press **Reload**.
2. Buy the script with `market buy process_survey_tool:item` — it appears in the market.
3. After buying, run it: `adder ~/scripts/process_survey.adr`.

## Installation and persistence

Family: shops. The plugin folder never touches other saves; the result stays in the save even if the plugin is disabled.
