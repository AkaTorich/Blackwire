# Cashflow Summary Tool

Report available funds and outstanding debt.

## Start here

1. Put this folder next to your other plugins and press **Reload**.
2. Buy the script with `market buy cashflow_summary_tool:item` — it appears in the market.
3. After buying, run it: `adder ~/scripts/cashflow_summary.adr`.

## Installation and persistence

Family: shops. The plugin folder never touches other saves; the result stays in the save even if the plugin is disabled.
