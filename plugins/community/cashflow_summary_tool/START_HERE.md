# Cashflow Summary Tool

Report available funds and outstanding debt.

## Start here

Run `cashflow_summary_tool_open` or `cashflow_summary_tool_status` for instructions. The item is listed in the script market.

Purchase: `market buy cashflow_summary_tool:item` (25 credits).

Run the purchased tool with `adder ~/scripts/cashflow_summary.adr`.

## Installation and persistence

Copy this plugin folder into the directory opened by **Plugins → Open folder**, then Reload. It is independent of the other 99 plugins. Created game content remains in the save after disabling a plugin. Names, commands and addresses are unique within this pack.
