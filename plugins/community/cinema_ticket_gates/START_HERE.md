# Турникеты кинотеатра

Перекупщик выдал дубликаты пропусков на уже заполненный сеанс.

## Начало

1. Положи эту папку рядом с другими плагинами и нажми «Перечитать».
2. Открой окно подсказки командой `cinema_ticket_gates_open` или нажми «Старт».
3. В терминале запусти `cinema_ticket_gates_start`.
4. Прочитай письмо «Турникеты кинотеатра: первая зацепка» в игровой почте.
5. Открой `http://198.22.16.1/` в игровом браузере и запусти `probe 198.22.16.1`.
6. Разобраться с контроллером и восстановить его рабочую запись.

## Подсказки

- Если `probe` показывает активный файрвол, обойди его командой `firewall <адрес>`. При промахе попробуй ещё раз и следи за подозрением.
- На первом узле ищи собственную службу плагина — `ticket_gate`.
- Для доступа нужно слабое место «entry», а не просто утечка данных.
- Внутри устройства посмотри `/etc/maintenance-note.txt` — там адрес записи.
- Команда `cinema_ticket_gates_status` показывает прогресс без сброса.
- Награда: 120 ₵, выплачивается один раз. Повторный запуск Start не дублирует содержимое и не сбрасывает прохождение.

## Если хочешь готовое решение

`research -h 3 198.22.16.1 cinema_ticket_gates:records_entry`

Свой исходник: `exploit new ~/scripts/my_exploit.adr 198.22.16.1 cinema_ticket_gates:records_entry`. Заполни payload по подсказкам в игре.

Готовый редактируемый инструмент: `market buy exp_overflow`.

`exploit -f ~/scripts/exp_overflow.adr -s cinema_ticket_gates:records_entry 198.22.16.1`

Прочитай `/srv/records/admissions.csv` на последнем узле — там сохранённая запись.

## Установка и память

Семейство: устройства. Организация: корпорация. Папка плагина не трогает чужие сохранения; созданные устройства и задания сохраняются вместе с миром.
