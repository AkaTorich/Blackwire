# Route Trace Tool

Report the current connection chain and proxy exit.

## Start here

Run `route_trace_tool_open` or `route_trace_tool_status` for instructions. The item is listed in the script market.

Purchase: `market buy route_trace_tool:item` (20 credits).

Run the purchased tool with `adder ~/scripts/route_trace.adr`.

## Installation and persistence

Copy this plugin folder into the directory opened by **Plugins → Open folder**, then Reload. It is independent of the other 99 plugins. Created game content remains in the save after disabling a plugin. Names, commands and addresses are unique within this pack.
